# 온라인 대국 · 실시간과 턴제

`dist/online.html`은 사람끼리 플레이하는 초대방이다. 기존 2인/4인 오토마 화면과 저장 키를 유지하며 별도 온라인 진입 링크만 추가한다. 방 생성 시 2인 맵(2명) 또는 4인 맵(4명)을 고른다. 계정, 공개 매칭, 랭킹, 채팅, 모드 전환, AI 대체는 제공하지 않는다.

## 플레이

1. 온라인 대국에서 맵·실시간/턴제·속도를 고르고 방을 만든다.
2. **초대 링크**를 친구들에게 전달한다. 입장자는 이름을 입력해 자기 자리를 받는다.
3. 선택한 맵의 참가자 모두 준비하면 방장이 시작한다.
4. 각자 자기 손패로 카드 → 행동 → 세부 선택 → 행동 확정을 진행한다. 확정된 행동은 되돌리지 않는다.
5. 브라우저를 닫아도 게임은 서버에 저장된다. 같은 기기의 내 대국 목록이나 **개인 재접속 링크**로 돌아올 수 있다. 개인 링크는 자리의 접근 권한이므로 다른 사람에게 공유하지 않는다. 회원 계정이 없어 개인 링크와 기기 저장을 모두 잃으면 자동 복구할 수 없다.

## 시간 정책

| 모드 | 빠름 | 보통 | 느림 | 무제한 |
| --- | --- | --- | --- | --- |
| 실시간 | 초기/상한 3분, 턴 시작마다 +1분 | 초기/상한 5분, +2분 | 초기/상한 10분, +3분 | 시계 없음 |
| 턴제 | 자기 턴 12시간 | 자기 턴 24시간 | 자기 턴 48시간 | 마감 없음 |

실시간은 현재 플레이어의 시계만 흐른다. 첫 턴에는 초기 시간으로 시작하고 이후 자기 턴이 시작할 때 보충한다. 두 행동 사이에는 보충하지 않는다. 턴제도 첫 행동 후 마감을 갱신하지 않으며 다음 플레이어로 차례가 넘어갈 때 새 마감을 정한다. 연결 끊김/새로고침으로 시계가 멈추거나 초기화되지 않는다. 서버 시각이 기준이다.

시간 초과는 자동 패스/패배/오토마 대체를 발생시키지 않는다. 현재 참가자 이외의 사람이 시간을 연장할 수 있다. 대국 중단은 참가자 전원의 동의가 있어야 한다. 친구 초대방용 정책이며 경쟁전의 제재/이탈 처리와 구분한다. 활동 시간대와 야간 정지는 아직 없다.

## 서버와 비공개 정보

- `multiplayer/worker.mjs`: Cloudflare Worker + 방마다 SQLite Durable Object. HTTP 명령, WebSocket, 하이버네이션, 영구 저장, 차례/마감 알림.
- `multiplayer/room.mjs`: 준비, 시작, 개인 시계, 턴 마감, 인증된 자리, 버전 검사, 중복 명령 영구 기록, 전원 중단 동의.
- `multiplayer/engine.mjs`: 기존 FourHuman/FourPlayer 규칙을 재사용한다. 행동하는 자리를 임시 0번으로 교환하고 모든 소유권/순서/보상/정산을 원래 자리로 돌린다. Automa 후보 가지치기로 사람의 선택지를 제한하지 않는다.
- 클라이언트는 합법 선택지의 번호만 전송한다. 서버가 현재 상태로 선택을 재실행해 금액/카드/자원/소유권/순서를 확정한다. 요청으로 보낸 상태/결과/플레이어 ID는 채택하지 않는다.
- 시작과 2시대 카드 분배는 암호학적 셔플을 사용한다. 첫 턴 순서와 미공개 유전 보상 위치도 별도로 셔플한다. 공개 배치로 카드/유전 순서를 역산할 수 없도록 기존 32비트 시드 셔플과 분리한다.
- 플레이어 투영은 허용한 필드만 전송한다. 다른 사람의 패, 모든 덱의 순서, seed, AI 메모리, 미공개 유전 값, 자리 인증 키는 제외한다. 원본 상태 전체를 publicState로 전송하지 않는다.
- 취소 가능한 미리보기에는 보충/2시대 새 손패와 새로 공개되는 유전의 보상·효과·로그를 보내지 않는다. 유전을 연 뒤 추가 선택이 필요하면, 먼저 명시적으로 행동을 고정한 뒤 보상을 공개한다. 고정한 카드/첫 건설은 바꿀 수 없고, 고정 정보는 서버에 저장해 재접속 후 이어간다.
- HTTP/WebSocket 핸들러와 알림용 alarm은 방 안에서 직렬 처리한다. 상태와 명령 처리 기록은 한 저장 문서로 함께 기록한 다음 각자의 view를 전달한다. 시계 갱신은 초마다 쓰지 않고 기준 시각과 잔여 시간으로 계산한다.

## 알림

‘차례 알림 켜기’를 누른 사람이 브라우저에서 허용한 경우에만 Web Push를 등록한다. 새 차례와 턴제 마감 1시간 전/시간 초과에 알린다. Service Worker는 알림만 담당하고 기존 게임의 요청을 가로채거나 캐시하지 않는다. 알림에 손패/자리 인증 키를 넣지 않는다. 실제 전달은 기기·브라우저의 알림 지원과 설정, 푸시 서비스에 의존한다. iOS 등에서는 홈 화면 설치가 필요할 수 있다.

서버는 VAPID_PRIVATE_KEY / VAPID_PUBLIC_KEY / VAPID_SUBJECT를 Cloudflare secret으로 받는다. 개인 키는 소스·배포 파일에 넣지 않는다. 푸시 구독 주소는 브라우저 제공 서비스 도메인만 허용하고 리다이렉트를 따르지 않는다. 기기 알림 허용이나 실제 사용자에게 전송하는 검증은 자동으로 수행하지 않는다.

## 개발과 배포

`multiplayer/`에서 lockfile에 맞춰 의존성을 설치하고 `wrangler dev --port 8792`로 서버를 실행한다. Pages 미리보기는 `node scripts/serve.cjs` (4194). 로컬 주소에서는 자동으로 로컬 서버를 사용한다. Worker 설정의 허용 출처와 `dist/online/config.js`의 공개 주소를 함께 관리한다. Worker를 별도 배포한 다음 기존 Sites/Pages의 정적 파일을 게시한다.

검증: `node --test tests/multiplayer.test.cjs`; 전체 검사는 `node --test tests/*.test.cjs`. 실행 중인 서버 검사는 `node multiplayer/smoke.mjs [endpoint]`. Smoke는 오직 새로 생성한 합성 검증방에서 2/4명 HTTP/WS 접속, 2인 62행동·4인 124행동, 재접속, 패 비공개, 중복 명령을 검증한다. 기존 사용자의 대국을 시험 데이터로 사용하지 않는다.

현재 범위: 친구 초대방 초기 버전. 공개 매칭용 생성 요청 제한, 계정 복구/다른 기기의 대국 목록 동기화, 서버 버전 간 규칙 고정/진행 중 방 마이그레이션, 운영 보관/정리 정책은 추가 설계가 필요하다. 알림 실패가 확정된 행동을 취소하지 않는다.

## 맵별 규칙과 호환성

2인 맵은 기존 2인 규칙에서 분리한 `online/two-core.js`와 검토된 2인 좌표를 변환한 `online/two-data.json`을 사용한다. `node scripts/build-online-two.cjs`로 두 파일을 함께 재생성한다. 기존 2인 앱의 저장/DOM 초기화는 실행하지 않는다. 32장 덱, 4개 유전, 서부·캐나다·보스턴 상인, 원자재 시장 자원별 2개를 유지한다. 4인 맵은 기존 64장 덱·5개 유전·원자재 시장 자원별 3개와 지도/해금 규칙을 유지한다.

방의 맵과 인원은 생성 후 고정한다. 시작 조건·자리 수·개인 시계·전원 중단 동의·시대 정산은 실제 인원을 사용한다. 맵 필드가 없는 기존 방은 4인 맵으로 해석한다. 기존 4인 로컬 저장 검증은 계속 4인 전용이다. 플레이어의 2/4인 로컬 저장을 온라인 저장으로 이관하지 않는다.

## 기존 오토마 화면과 공통 조작

온라인도 기존 next/table/physical/available/wide/four-player CSS와 실물 컴포넌트를 사용한다. 데스크톱은 사용 가능 타일–공용 지도–손패·행동의 동일한 배치, 모바일은 동일한 카드 이름 버튼·행동 버튼·하단 메뉴를 사용한다. 게임/개인판/대국 설정/기록 메뉴에서 초대·재접속·알림·중단 관리와 공용 배치를 확인한다. 카드 또는 행동을 먼저 선택할 수 있고 도시/산업 필터, 지도/목록 선택, 실행 결과 미리보기·행동 확정을 제공한다. 기존 오토마 배치 화면에서 선택한 맵을 온라인 방 설정으로 전달한다.

online/table-ui.js는 공개된 removed/networkBuilt/lightTrains만 기존 표시 함수에 전달한다. 상대 손패나 덱을 복원하거나 브라우저에서 행동을 실행하지 않는다. 실행 전 취소와 확정 전 서버의 유전 공개 잠금은 유지한다. 확정된 온라인 행동은 다른 참가자와 공유되므로 되돌리기를 제공하지 않는다. 온라인 화면 설정은 별도 키에 저장한다.

온라인 2인 네트워크는 기존 오토마 2인의 기물 크기·비율·방향과 기물 단위 정보창을 사용한다. 일반 상태의 경로 전체 마우스 강조를 제거하고, 선택 중인 경로는 기존 금색/청록색 영역으로 표시한다. 네트워크 선택은 공통 network-picker.css의 실물 이미지·설명·강조 효과를 사용하며, 선택 데이터의 공개 networkId와 원래 인덱스를 보존한다. 밴더빌트 후보는 체크박스로 표시한다. 4인 지도와 게임 실행 규칙에는 영향이 없다.

2026-10-29: 같은 네트워크 표시를 온라인 4인과 로컬 4인 오토마에도 적용했다. 공통 online/network-presentation.js가 각 맵의 기존 기물 중심·회전을 사용하며, 폭은 산업 슬롯 중앙값의 110%, 높이는 폭/1.75이다. network-presentation.css와 network-picker.css를 두 진입 화면에서 함께 사용한다. 설치 기물 단위로 소유자·효과·현재 자원을 확인하고, 지도 대상 선택 중에는 정보 클릭 영역을 숨긴다. 4인에 별도 강조 영역이 없는 경로는 기존 좌표의 금색/청록색 곡선으로 합법 대상을 표시한다. 선택·자원 표시·정보창은 서버/로컬 규칙 상태를 읽는 표시 기능이며 서버 변경이나 Worker 재배포는 필요하지 않다.
